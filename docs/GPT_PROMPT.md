## המוצר
חנות וירטואלית בתלת-ממד שעובדת בדפדפן – במחשב, בטלפון ובמשקפי VR (WebXR).
המבקר בוחר דמות, נכנס לרחבה, ורואה את משאית S.Y שחונה במרכז כיכר קניות מצולמת, ומסביבה מתחם קניות ("S.Y Mall") עם חנויות של עסקים אחרים. קונים מכל החנויות בסל אחד, משלמים ב-PayPal ומקבלים משלוח עד הבית.

### מה כבר בנוי ועובד
1. **סצנה:** A-Frame 1.6 (three.js). הרחבה היא צילום 360 אמיתי (Schadowplatz, Poly Haven, CC0) שמוקרן לרצפה (Grounded Skybox), עם תופס צללים ותאורה מאותו צילום. עיבוד תמונה קולנועי משלי (bloom, ACES, דירוג צבע), כבוי במשקף.
2. **המשאית:** בנויה בקוד, עם מיתוג S.Y, דלפק טלפונים, קיר אביזרים וקופה. 10 מוצרים בקטלוג (טלפונים S.Y X Pro / X / A5, טאבלט, שעון, אוזניות, רמקול, מטען, סוללה ניידת, כיסוי).
3. **דמויות:** אנשים וכלבים אמיתיים מספריית Microsoft Rocketbox (MIT), עם אנימציות מצולמות (הליכה, ריצה, נפנוף, ריקוד, דיבור, ישיבה, הקלדה בטלפון). המבקר בוחר דמות מתוך גלריה. יש דמות מותאמת עם הפנים של בעל העסק מתמונה. מצלמה מאחורי הכתף.
4. **קנייה:** פס מוצרים עם כרטיסים גדולים בתחתית המסך לפי האזור, חלון מוצר (צבעים, כמות, "נסו את המכשיר" עם מצלמה אמיתית בתוך הטלפון), סל, טופס משלוח עד הבית עם מועד, ותשלום PayPal. המחירים מחושבים תמיד בשרת.
5. **מוכרת AI – "נועה":** עונה בעברית דרך Claude API בשרת (החזרת JSON: reply + products). כשאין שרת או מפתח – עונה מהקטלוג לפי מילות מפתח.
6. **חברתי:** מבקרים בזמן אמת (WebSocket), צ'אט עם סינון ובטיחות לילדים, קבוצות וסל משותף.
7. **מתחם הקניות S.Y Mall:** 8 חנויות פופ-אפ (4 בכל צד). עסקים שוכרים חנות במנוי חודשי ב-PayPal Subscriptions:
   - מסלולים: דוכן 149 ₪ (12 מוצרים), חנות 349 ₪ (40), חנות דגל 749 ₪ (150) לחודש.
   - עמוד הרשמה `merchant.html`: בחירת מסלול ומקום, פרטי עסק, חוזה שכירות, תשלום, ועמוד ניהול עם קישור אישי (פרטים, מוצרים עם תמונות, הזמנות, ביטול).
   - השרת מאמת את המנוי מול PayPal לפני פתיחת החנות, ומקבל עדכונים ב-Webhook.
   - הלקוחות משלמים לקופת המתחם, וכל עסק רואה את ההזמנות שלו. ההעברה לעסקים כרגע ידנית.
   - חנויות לדוגמה (פרחים, קפה, צעצועים) מוצגות עד שהמקום מושכר, ואי אפשר לקנות מהן.

### טכנולוגיה וקבצים
- **שרת:** Node.js + Express (`server.js`), WebSocket (`live.js`), מתחם (`mall.js`), מוכרת (`seller.js`). נתונים בקבצי JSON בתיקייה `data/`.
- **לקוח:** `index.html`, `css/style.css`, ו-`js/`: `app.js` (חנות, סל, תשלום, ניווט), `truck.js`, `city.js` (רחבה מצולמת), `plaza.js`, `humans.js` (דמויות), `social.js`, `play.js` (מוכרת, נסו את המכשיר, כדור לכלב), `mall3d.js`, `brand.js`, `post.js`, `products.js`.
- **אירוח:** Render (`render.yaml`). משתני סביבה: `PAYPAL_CLIENT_ID`, `PAYPAL_CLIENT_SECRET`, `PAYPAL_ENV`, `ANTHROPIC_API_KEY`, `PAYPAL_WEBHOOK_ID`, `MALL_DEMO`.
- **קוד:** ב-GitHub, ריפו `phonetruck21-commits/sy`, ענף `ccr-daead614-8azb0g`.

### מה עוד פתוח
- המשאית עדיין בנויה בקוד ולא סרוקה. סריקה של המשאית האמיתית (Polycam / Scaniverse) או מודל מקצועי ישדרגו את המראה הכי הרבה.
- ב-Render החינמי התיקייה `data/` נמחקת בכל עדכון. צריך Render Disk או מסד נתונים (למשל PostgreSQL) לפני שעסקים אמיתיים נרשמים.
- העברת כסף אוטומטית לכל עסק (PayPal Multiparty או Stripe Connect).
- לא נבדק עם PayPal אמיתי, עם מפתח Claude אמיתי ועל משקף VR אמיתי.
- חוזה השכירות צריך בדיקה של עורך דין.
- שירותי המעבדה (תיקונים, מצלמות, בית חכם) עדיין לא נמכרים באתר – רק מפנים לטלפון.
