# מעבר ל-Unreal Engine 5 – מדריך ותוכנית עבודה

המטרה: אותה חוויה (משאית סלולר ברחבה, משפחות, חיות, צ'אט, קנייה משותפת ומשלוח),
אבל בגרפיקה של משחק AAA – אנשים ריאליסטיים, תאורה אמיתית ועולם שאפשר להסתובב בו חופשי.

**מה נשאר כמו שהוא:** השרת שכבר בנינו (`server.js`, `live.js`, `seller.js`) ממשיך לעבוד
כ"מוח" של החנות. אפליקציית Unreal מדברת איתו בדיוק כמו האתר: מוצרים, הזמנות, PayPal,
משלוחים, צ'אט, קבוצות ומוכר/ת AI. האתר הנוכחי יכול להמשיך לעבוד במקביל.

---

## 1. מה צריך במחשב

| | מינימום | מומלץ |
|---|---|---|
| מערכת | Windows 10/11 64-bit | Windows 11 |
| כרטיס מסך | NVIDIA RTX 2070 / AMD RX 6700 | RTX 3070 ומעלה |
| זיכרון | 32GB | 64GB |
| דיסק | 200GB פנויים, SSD | NVMe 1TB |
| משקף | Meta Quest 2/3 עם כבל Link או Air Link | Quest 3 |

> נתחיל באפליקציה למחשב שמתחברת למשקף (PC VR). זה הכי פשוט, ונותן את הגרפיקה הכי טובה.
> גרסה שרצה לבד בתוך ה-Quest מחייבת להוריד הרבה מהגרפיקה – נחליט על זה אחר כך.

## 2. התקנה (בערך שעה)

1. מתקינים את **Epic Games Launcher** מ-epicgames.com ונכנסים עם חשבון Epic (חינם).
2. בלשונית **Unreal Engine → Library** מתקינים את הגרסה העדכנית של **Unreal Engine 5**.
3. מתקינים את **Meta Quest Link** (האפליקציה של Meta למחשב) ומחברים את המשקף.
4. יוצרים פרויקט חדש: **Games → Virtual Reality**, עם **Blueprint**, **Maximum Quality**, **Starter Content**.
   שם הפרויקט: `NovaStore`.

## 3. חומרים ריאליסטיים בחינם

| מה | מאיפה | הערות |
|---|---|---|
| אנשים ריאליסטיים | **MetaHuman Creator** (של Epic) | חינם לשימוש ב-Unreal. יוצרים את המוכר/ת, את משפחות הרקע, ותבנית לדמויות המבקרים |
| עיר ריאליסטית | **City Sample** (ב-Fab) | העיר מהדמו של "The Matrix Awakens" – חינם. רחובות, בניינים, תאורה |
| חומרים, צמחים, אבנים | **Quixel Megascans** ב-Fab | חינם לשימוש ב-Unreal. יש גם דקלים וצמחייה טרופית |
| כלבים וחתולים מונפשים | **Fab** – לחפש dog / cat animated | יש חינמיים ובתשלום (בערך 20–60$) |
| משאית | Fab – לחפש box truck / food truck | בתשלום סמלי, או לבנות מחדש לפי העיצוב הקיים |

## 4. התוכנית – שלבים

**שלב 1 – העולם (שבוע 1)**
- רחוב בסגנון מיאמי מתוך City Sample או מ-Megascans: רחבה, מדרכות, דקלים, בנייני פסטל, פנסים.
- תאורת שקיעה: Directional Light + Sky Atmosphere + Volumetric Clouds, עם Lumen לאור משתקף אמיתי.
- המשאית עם הצד שנפתח לחנות, מדרגות וסוכך.

**שלב 2 – הליכה חופשית כמו משחק (שבוע 1–2)**
- במחשב: Third Person – הליכה עם המקשים, ריצה, ישיבה על ספסלים, פתיחת דלתות.
- במשקף: תבנית ה-VR – הליכה עם הסטיק, טלפורט, יד שתופסת חפצים.
- בית קפה שנכנסים אליו ברחוב, דלתות שנפתחות.

**שלב 3 – דמויות (שבוע 2)**
- יוצר דמויות למבקרים מבוסס MetaHuman (פנים, שיער, בגדים) במקום הדמויות הנוכחיות.
- מוכר/ת MetaHuman בתוך המשאית, עם אנימציות דיבור.
- משפחות רקע שמטיילות עם כלבים (AI Move To על נתיבים).

**שלב 4 – לנסות טלפון באמת (שבוע 3)**
- מרימים טלפון (Grab Component), והוא נדלק: מסך שהוא **Widget Component** עם מסך נעילה, החלקה ואפליקציות.
- מצלמה אמיתית: **Scene Capture 2D** שמצלמת את הרחבה – מצלמים "תמונה" ורואים אותה בגלריה של הטלפון.
- החלפת צבע: Material Instance לכל צבע.
- רמקול: מנגן מוזיקה כשמפעילים אותו.

**שלב 5 – מוכר/ת שמדבר/ת (שבוע 3)**
- המבקר כותב או מדבר (Speech-to-Text של Windows/Meta), והשאלה נשלחת ל-`POST /api/seller`.
- התשובה מוצגת בבועה ונקראת בקול (Text-to-Speech), והמוצרים שהוזכרו נדלקים על המדף.

**שלב 6 – משחקים עם חיות וילדים (שבוע 4)**
- זורקים כדור, והכלב רץ ומביא אותו (Physics + AI Move To).
- מגלשה (Spline) וקרוסלה שעולים עליהן.
- חיפוש אוצרות: 5 טלפונים מוזהבים מוסתרים ברחבה. מי שמוצא את כולם מקבל קוד הנחה.

**שלב 7 – מבקרים יחד, קנייה ותשלום (שבוע 4–5)**
- חיבור ל-`wss://<השרת>/live` עם מודול WebSockets של Unreal: מבקרים בזמן אמת, צ'אט, קבוצות וסל משותף.
- תשלום: פותחים את דף התשלום של PayPal בתוך **Web Browser Widget**, עם טופס המשלוח. זה אותו תהליך שעובד היום.

## 5. החיבור לשרת הקיים

כל מה שהאפליקציה צריכה כבר קיים בשרת:

| מה | בקשה | תשובה |
|---|---|---|
| הגדרות תשלום | `GET /api/config` | `{ clientId, currency, env }` |
| יצירת הזמנה | `POST /api/orders` עם `{ items: { "מוצר\|צבע": כמות }, delivery: {...}, group }` | `{ id }` |
| גביית תשלום | `POST /api/orders/<id>/capture` | `{ status, captureId, amount, delivery }` |
| מוכר/ת AI | `POST /api/seller` עם `{ messages: [{ role, content }], kid }` | `{ reply, products: [ids] }` |
| מבקרים וצ'אט | WebSocket `/live` – הודעות `hello`, `pos`, `chat`, `emoji`, `anim`, `group-*`, `gcart`, `invite` | ראו `live.js` |
| קטלוג | `js/products.js` | מוצרים, מחירים, צבעים |

## 6. איך אני (Claude) עוזר בתוך Unreal

את Unreal אני לא יכול להריץ כאן בענן. יש שתי דרכים לעבוד יחד:

1. **הכי טוב:** במחשב שבו מותקן Unreal, מתקינים את **Claude Code** ואת התוסף שמחבר את Claude
   לעורך של Unreal (Unreal MCP). אז אני יכול לבנות ישירות בתוך הפרויקט: למקם אובייקטים,
   ליצור Blueprints ולחבר את הכול.
2. **חיבור המחשב לשיחה הזו:** באפליקציית Claude למחשב, נכנסים ל-**Settings → Claude Code → Remote Control**
   ומשתפים את תיקיית הפרויקט. ככה אני יכול לעבוד על הקבצים שבמחשב שלך מכאן.
