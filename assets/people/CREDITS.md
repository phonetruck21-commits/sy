# דמויות וכלבים

הדמויות, הכלבים והאנימציות בתיקייה הזו לקוחים מ-[Microsoft Rocketbox Avatar Library](https://github.com/microsoft/Microsoft-Rocketbox), ברישיון MIT (Copyright (c) Microsoft Corporation).
הם הומרו מ-FBX ל-glTF עם three.js (FBXLoader + GLTFExporter), הטקסטורות הוקטנו ל-WebP, והאנימציות קוצרו.
